Divide by w

The eye sits in front of a sheet. The house stands behind the sheet. Slide the eye closer or farther. Where a ray meets the sheet, that point is the drawing.

Parallel edges that run away from you meet at one vanishing point. The vanishing point sits on the horizon, level with the eye. The matrix stays the same when the eye moves. This corner's depth changes, and that changes w.

The matrix writes depth into w. Then x, y, and z are divided by w. A far corner has a larger w, so it shrinks more. In lesson 04, w marks a point or a direction. Here, w carries depth.

      Where this is used
      
    
        
  • A 3D camera in a game or an animated film uses this divide. A graphics programmer builds that camera. A layout artist or a camera artist places it.
    • 
        
  • Artists and illustrators draw lines to a vanishing point on a horizon. This is linear perspective. Painters have used it since the Renaissance.
    • 
        
  • On a phone, augmented reality uses the same divide, so a virtual object lines up with the camera.
    • 
        
  • In computer vision, a related idea is the pinhole camera. A photogrammetrist uses it to measure a real object from photographs. A real lens can add distortion, which this page leaves out.
